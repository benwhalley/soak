Hungarian Matching (Optimal 1-to-1 Assignment)

The Hungarian algorithm finds the optimal one-to-one pairing between themes that maximizes total similarity. Unlike many-to-many matching, each theme maps to at most one theme in the other set. Uses Shepard similarity (k={{ comp.stats.shepard_k_value }}) for mathematically valid averaging.

Optimal Transport (Many-to-Many Alignment)

Optimal Transport models how theme-mass can be distributed across the other set, allowing many-to-many mappings. Unlike Hungarian matching (which enforces one-to-one), OT permits themes to split or merge.

OT Similarity

{{ "%.3f"|format(comp.stats.ot.similarity) }}

Interpretation: Measures many-to-many conceptual correspondence. Allows themes in A to split across several B themes or vice versa. High = analyses share conceptual space even if labelled differently.

Null-Relative

{{ "%.3f"|format(comp.stats.ot.null_relative) }}

Interpretation: Places A-B alignment along scale from random (0) → perfect (1). Formula: (OT - null_mean) / (1.0 - null_mean). Values close to 0 indicate alignment is no better than random shuffling. High values indicate meaningful structure beyond chance.

Concentration

{{ "%.3f"|format(comp.stats.ot.concentration) }}

Interpretation: How tightly does similarity mass focus on a few theme pairs? High = both analyses converge onto same conceptual clusters. Low = diffuse relationships.

OT Baselines & Context
Null Distribution (Random Baseline)
  • Mean: {{ "%.3f"|format(comp.stats.ot.null_mean) }}
  • 95th percentile: {{ "%.3f"|format(comp.stats.ot.null_95pct) }}

Null distribution computed via 100 bootstrap iterations with random theme permutations. Shows what OT similarity looks like under meaningless alignment. If your OT similarity is close to this value, the alignment is no better than random.

Interpretation Guide
  • Null-relative ≈ 0: Alignment is random, no meaningful structure
  • Null-relative 0.3-0.5: Moderate alignment, some structure
  • Null-relative 0.5-0.7: Good alignment, clear thematic overlap
  • Null-relative > 0.7: Strong alignment, high correspondence

Similarity Metrics

Multiple similarity metrics are computed to provide different perspectives on theme alignment. Each metric captures different aspects of semantic similarity.

Cosine Similarity

What it measures: The cosine of the angle between theme embedding vectors. Ranges from -1 to 1, with 1 indicating identical direction.

Note: While intuitive, cosine similarity is not a true distance metric and should not be averaged. Use angular distance or Shepard similarity for more rigorous comparisons.

Continuous Values
Binary Match (threshold={{ comparison.config.threshold }})
Angular Similarity (Normalized)

What it measures: Uses the angular distance between vectors (arccos of cosine), normalized to [0,1] scale where 1 = identical and 0 = orthogonal (90° apart).

Why it's better: Angular distance is a proper metric that satisfies the triangle inequality, making it mathematically rigorous for averaging and comparison.

Shepard Similarity (k={{ comp.stats.shepard_k_value }})

What it measures: Applies exponential decay to angular distance, modeling a cognitively realistic similarity function. Formula: (exp(-k·θ) - exp(-k·π)) / (1 - exp(-k·π))

Interpretation: Higher values indicate tighter semantic alignment. Values around 0.30-0.45 suggest moderately similar but not identical themes. The k parameter controls decay rate (larger k = steeper decay).

Within-set baseline: Mean = {{ "%.3f"|format(comp.stats.within_set_stats.mean) }}, SD = {{ "%.3f"|format(comp.stats.within_set_stats.std) }} (based on {{ comp.stats.within_set_stats.n_pairs }} within-set theme pairs)

Percentile-Normalized Shepard

What it measures: Expresses cross-set similarity relative to the distribution of within-set similarities. A value of 0.80 means this theme pair is more similar than 80% of all within-set theme pairs.

Interpretation: Provides a within-corpus reference frame. Values > 0.80 indicate strong conceptual overlap. Answers: "How good is this match compared to typical theme similarity?"

Z-Score Normalized Shepard

What it measures: Number of standard deviations above or below the typical within-set similarity. Positive = stronger than average; negative = weaker than average.

Interpretation: Z-score of +1.2 means "substantially stronger than average similarity"; -0.5 means "below typical internal similarity". Useful for identifying outliers and exceptional matches.
