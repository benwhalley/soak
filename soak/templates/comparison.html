Interpreting this plot: UMAP is a non-linear dimensionality-reduction method that prioritises preserving local neighbourhood structure rather than global variance. Best Matches (1:1)

The Hungarian algorithm finds the optimal one-to-one pairing that maximizes total similarity. Each theme maps to at most one theme in the other set -- no reuse allowed.

Intuition: "If I had to explain set B's themes to someone who only knew set A, which single theme in A would each B theme correspond to, with no reuse?"

What this enables: Hungarian matching makes precision/recall well-defined by removing ambiguity about what counts as a "match". After matching: each pair = one prediction; unmatched A themes = false negatives; unmatched B themes = false positives.

Limitation: This penalises legitimate theme refinement (splitting one theme into two is treated as error). Use OT if you want to reward decomposition.

{% if ot_k.ot.shared_mass_relative is defined %} ▶ Calculation and interpretation

Relative shared mass. This metric quantifies alignment quality relative to a null baseline of semantically unstructured text. The relative score is computed as:

relative = (observed - null_mean) / (1.0 - null_mean)

where observed is the shared mass from the actual comparison, null_mean is the mean shared mass from N=100 null comparisons (using word-salad permutations), and 1.0 represents the theoretical maximum (perfect alignment). The metric thus represents the proportion of possible improvement over random that was achieved.

Null distribution. Null comparisons are generated by randomly permuting words within each theme's embedded text while preserving word count. This destroys semantic coherence while maintaining surface-level statistical properties. Both directions are tested (A vs Bsalad and Asalad vs B) to ensure the null is symmetric.

Interpretation guidelines. The thresholds (0.3 = meaningful, 0.5 = good, 0.7 = strong) are heuristic guidelines rather than validated cutoffs. They provide rough orientation but should be interpreted in the context of the specific domain and research question. A relative score of 0.3 indicates the observed alignment captures approximately 30% of the maximum possible improvement over chance -- whether this constitutes "meaningful" structure depends on the application.

{% if ot_k.ot.avg_cost_relative is defined %} ▶ Calculation and interpretation

Relative average cost. This metric quantifies the quality of theme-to-theme alignments relative to a null baseline. The relative score is computed as:

relative = (null_mean - observed) / null_mean

where observed is the mass-weighted average transport cost (1 - cosine similarity) from the actual comparison, and null_mean is the mean average cost from null comparisons. The metric represents the proportional reduction in transport cost compared to random alignment.

Relationship to shared mass. Average cost and shared mass capture complementary aspects of alignment quality. Shared mass measures how much of the thematic content could be matched; average cost measures how well matched themes align semantically. High shared mass with high average cost suggests forced alignments between dissimilar themes; low shared mass with low average cost suggests selective matching of only the best correspondences.

Interpretation. The score ranges from 0 (no improvement over random) to 1 (perfect alignment with zero cost). There are no validated cutoffs for this metric. A score of 0.22, for example, indicates transport costs were 22% lower than expected under the null hypothesis of random semantic structure. Whether this represents meaningful alignment depends on the domain, the granularity of themes, and the research question.

▶ About the colour scale

Colour scale calibration. Link colours represent the cosine similarity between connected themes, mapped to a green-amber-red gradient. To ensure comparability across K values, all plots use a shared colour scale derived from the default K={{ "%.2f"|format(comp.stats.default_k) }} transport plan.

The scale endpoints are set to the minimum and maximum similarity values observed among links in the default K solution (similarity range: {{ "%.2f"|format(comp.stats.color_sim_min) }}--{{ "%.2f"|format(comp.stats.color_sim_max) }}). Green indicates the highest-similarity matches; red indicates the lowest-similarity matches within this analysis.

This calibration means that as K increases and additional lower-quality matches are transported, these appear as progressively redder links. At low K values, only the best matches (greenest links) are transported; higher K values force the algorithm to include weaker alignments. The consistent scale across K values allows direct visual comparison of match quality.

Note: Because the scale is normalised to each comparison's observed range, colours are not directly comparable across different pairwise comparisons. Within a single comparison, however, the colour scale provides an intuitive representation of relative alignment quality across the full range of K values examined.
